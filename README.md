# Markdown Viewer

A project workspace for a browser-based Markdown viewer.

## Project status

This repository currently contains the project description only. The application source code and runnable build are not included yet. The capabilities below are proposed goals, not implemented features.

## Planned direction

- Live Markdown preview
- Responsive editor and preview layout
- Safe rendering of user-provided Markdown
- Optional export support
- Clear keyboard and accessibility support

## Development

The implementation language, dependency list, and run commands will be added when the application source is introduced.

## Contributing

Please keep feature claims aligned with working code, document dependencies, and include basic manual or automated tests for new behavior.
